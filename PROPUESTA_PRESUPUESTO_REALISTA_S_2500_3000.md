## 4. CONFIGURACIÓN DE 3-4 LECTORES POR LAPTOP

### El problema
Si conectas 4 lectores USB a una laptop, todos "escriben" en el mismo buffer. Sin configuración, no se sabe qué lector envió qué lectura.

### La solución implementada

Cada lector se configura con un **prefijo único** (códigos de barras de configuración en el manual del lector). Ejemplo:

| Lector | Prefijo | Lo que envía |
|---|---|---|
| Entrada Norte - Puerta Principal | `N1\|` | `N1\|72345678\|signature` |
| Entrada Norte - Puerta Lateral | `N2\|` | `N2\|71234567\|signature` |
| Entrada Norte - Acceso Especial | `N3\|` | `N3\|73456789\|signature` |
| Entrada Sur - Puerta Principal | `S1\|` | `S1\|74567890\|signature` |
| Entrada Sur - Puerta Lateral | `S2\|` | `S2\|75678901\|signature` |
| Entrada Sur - Acceso Especial | `S3\|` | `S3\|76789012\|signature` |

**Tiempo de configuración:** 5 minutos por lector (solo escanear 2-3 códigos de barras del manual).

### Visualización en pantalla

El portero ve un panel con cards de cada lector que se iluminan según el resultado:

```
┌─────────── ENTRADA NORTE ───────────┐
│                                     │
│  ┌────┐  ┌────┐  ┌────┐            │
│  │ N1 │  │ N2 │  │ N3 │            │
│  │ ◀  │  │ ●  │  │ ▶  │            │
│  │Sofía│ │    │  │    │            │
│  │07:32│ │    │ │    │            │
│  └────┘  └────┘  └────┘            │
│                                     │
│  [Resultado de la última marcación] │
└─────────────────────────────────────┘
```

### Hardware necesario por entrada

- 3-4 lectores USB
- 1 hub USB con alimentación propia (obligatorio)
- 3-4 cables USB extensor
- 1 regleta

Para enviar notificaciones a padres (tardanzas, ausencias).

- **Resend (recomendado):** 3,000 emails/mes GRATIS

### Cálculo de emails necesarios

Con 1,500 alumnos:
- Tardanzas: ~5% llegan tarde diariamente = 75 emails/día × 22 días = 1,650/mes
- Resumen al director: 1/día × 22 = 22/mes
- **Total: ~1,700 emails/mes** → Cabe en el plan gratuito
